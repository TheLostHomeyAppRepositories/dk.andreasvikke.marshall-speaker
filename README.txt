Control your Marshall Speaker Devices from within Homey (only Wi-Fi Speakers).

Supported devices

- Legacy Marshall Wi-Fi speakers using the Frontier Silicon API
- Marshall Heston 120 and 60 using Google Cast

Heston 120 and 60

The Heston 120 and 60 is discovered automatically on the local network. The integration
supports volume, mute, presets 1–3, bass, treble, input source, and the Music,
Movie, Night, and Voice sound modes. The soundbar and Homey must be connected to
the same network. Presets must first be saved with the Marshall mobile app.
